Linux

          

            
Install

            
    
              
  1. In a terminal in your downloads folder, extract it and set up the shortcut once:
                
    tar -xzf ContextSnap-1.0.1-linux-x64.tar.gz
./contextsnap-1.0.1-linux-x64/contextsnap --install
    
              
    2. 
              
  2. Press CtrlAltShiftC, then paste. On Wayland desktops other than GNOME, --install prints a command to add as a shortcut in your keyboard settings.
    3. 
            

          

          

            
Requirements

            
    
              
  • 64-bit (x64) Linux, X11 or Wayland. No .NET install needed.
    • 
              
  • wl-clipboard (Wayland) or xclip (X11) to copy, and wmctrl to list windows:
                
    sudo apt install wl-clipboard xclip wmctrl

Privacy

        
ContextSnap is built to share only what you choose, with no one but you.

      

      
    
        
  • You control every capture
    It captures only when you press the shortcut. Nothing watches or records in the background.
    • 
        
  • Your data stays local
    Snapshots are made on your computer and go only to your clipboard. No uploads, accounts, or cloud.
    • 
        
  • Sensitive information is redacted
    Keys, tokens, passwords, and email addresses are replaced before copying. It can miss things, so look before you paste.
    • 
        
  • Private data stays untouched
    It never reads file contents, password fields, cookies, browser history, or environment variables.

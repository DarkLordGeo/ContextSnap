How it works

  1. 1

    Press the shortcut

    Ctrl+Alt+Shift+C on Windows by default. On Linux, bind the contextsnap command to any shortcut. Nothing is read before you do.

  2. 2

    Context is collected and redacted

    Open apps, Git state, system basics, and on Windows the visible text of the window you are using. Secrets, tokens, and email addresses are redacted on your machine.

  3. 3

    Paste the Markdown

    The snapshot lands on your clipboard with a short confirmation. Review it, then paste it wherever you need it.

What a snapshot can include

Each source can be turned off. Size limits keep the result short enough to be useful.

  • Visible text

    On Windows, text on screen in the focused window, read through accessibility APIs with on-device OCR as a fallback. Password fields are skipped.

  • Apps and windows

    Names and titles of open apps (on Linux, X11 and XWayland apps). Password managers and private browsing windows are excluded by default.

  • Git state

    Branch, upstream, changed file names, and recent commit subjects. Git is run read-only; diffs and file contents are never read.

  • System basics

    Operating system, architecture, CPU count, and memory, plus running developer tools and Desktop items. On Windows also File Explorer folders.

Private by design

ContextSnap is a capture tool, not a monitor. It does nothing until you press the shortcut or click Capture, and it keeps no history.

  • Captures only when you trigger it
  • Processed and redacted locally
  • No network requests, telemetry, or accounts
  • Nothing captured is saved to disk

Redaction is pattern-based and cannot catch every secret. Window titles and file names can still reveal what you work on, so review the snapshot before you share it. Read the privacy details.

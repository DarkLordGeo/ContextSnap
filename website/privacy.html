Privacy

ContextSnap captures context only when you ask it to, processes it on your computer, and puts the result on your clipboard. That is the whole data flow.

When it captures

  • Only when you press its shortcut, click Capture or choose Capture in its optional notification-area menu, or run ContextSnap --capture / --print on Windows, or when you run contextsnap on Linux (usually through its shortcut).
  • It starts with your computer and waits in the background for the shortcut, but it never monitors activity, records the screen continuously, or captures on its own. On Linux X11 desktops, the background instance receives only its own key combination, not other keystrokes.

What a snapshot can include

  • On Windows, visible text of the window you are using (optionally other visible windows), read through accessibility APIs, with on-device OCR when an app exposes too little text.
  • Names and titles of open apps and windows; Git branch, status, changed file names, and recent commit subjects; basic system information.
  • Running developer tools and Desktop item names. On Windows also: open File Explorer folders and, only if you turn it on, browser tab titles and the active tab's address.

What it never collects

  • Password fields, file contents, Git diffs, cookies, browser history, clipboard history, environment-variable values, or process command-line arguments.
  • Password managers and private or incognito browser windows are excluded by default. You can add your own app and window-title exclusions.

Processing and storage

  • Everything is processed on your computer. The apps make no network requests and have no telemetry, accounts, or cloud features.
  • Secrets, tokens, and email addresses are redacted locally before anything is copied. Redaction is pattern-based and cannot catch every secret, and window titles or file names can still reveal what you work on, so review what you paste.
  • Nothing captured is saved. Settings are stored on your computer only. On Windows, errors are written to a small local diagnostics log (error types and redacted messages, never snapshot contents).
  • On Windows, copies are marked so clipboard history and cloud sync skip them (on by default). On Linux, a clipboard manager you run may keep its own copy.

Permissions

  • Windows: no administrator rights. The optional Start with Windows setting adds a shortcut to your Startup folder.
  • Linux: no root access. contextsnap --install copies the app to ~/.local/bin and adds either a GNOME keyboard shortcut or an autostart entry; --uninstall removes them. Windows are listed with wmctrl and xprop, copying uses wl-copy, xclip, or xsel, and only process names and executable paths are read from /proc.

This website

  • Google Analytics runs only if you accept it in the cookie banner. It then loads a script from Google and sets cookies to recognize returning visitors. Until you accept, nothing is loaded from Google. You can change your choice at any time with "Cookie settings" at the bottom of each page; declining removes the Google Analytics cookies.
  • Page views are also counted with Vercel Web Analytics, which is served from this site and does not use cookies. No other analytics, external fonts, or third-party scripts.
  • The ContextSnap apps themselves send no analytics or telemetry.
  • Download buttons link to files hosted on GitHub Releases, so a download is served by GitHub under its own privacy policy.

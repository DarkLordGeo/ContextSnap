Privacy

ContextSnap captures context only when you ask it to, processes it on your computer, and puts the result on your clipboard. That is the whole data flow.

When it captures

  • Only when you press its shortcut, click Capture, or run ContextSnap --capture / --print on Windows.
  • It never monitors activity, records the screen continuously, or captures in the background.

What a snapshot can include

  • Visible text of the window you are using (optionally other visible windows on Windows), read through accessibility APIs, with on-device OCR when an app exposes too little text.
  • Names and titles of open apps and windows; Git branch, status, changed file names, and recent commit subjects; basic system information.
  • On Windows also: open File Explorer folders, running developer tools, Desktop item names, and, only if you turn it on, browser tab titles and the active tab's address.

What it never collects

  • Password fields, file contents, Git diffs, cookies, browser history, clipboard history, environment-variable values, or process command-line arguments.
  • Password managers and private or incognito browser windows are excluded by default. You can add your own app and window-title exclusions.

Processing and storage

  • Everything is processed on your computer. The apps make no network requests and have no telemetry, accounts, or cloud features.
  • Secrets, tokens, and email addresses are redacted locally before anything is copied. Redaction is pattern-based and cannot catch every secret, and window titles or file names can still reveal what you work on, so review what you paste.
  • Nothing captured is saved. Settings are stored on your computer only.
  • Copies are marked so Windows clipboard history and cloud sync, and macOS clipboard managers that honor the convention, skip them (both on by default).

Permissions

  • Windows: no administrator rights. The optional Start with Windows setting adds a shortcut to your Startup folder.
  • macOS: Accessibility lets ContextSnap read the active window's text. Screen Recording is optional and used only for on-device OCR when you capture. Without them, app, Git, and system context still work.

This website

  • No cookies, analytics, external fonts, or third-party scripts.
